# TWM — Technical Workforce Management

Конфигурируемое веб-приложение для управления внутренними техническими службами производственного предприятия: механика, электрика, энергетика, АСУ ТП, робототехника, метрология и другие инженерные подразделения.

**Репозиторий:** `uzbatsu-beep/HRMS`  
**Продуктовый baseline:** [интерактивный прототип v0.1](./TWM_Configurable_Prototype_v0.1.html)  
**План разработки:** [docs/DEVELOPMENT_PLAN.md](./docs/DEVELOPMENT_PLAN.md)  
**Инструкции AI-разработчику:** [GEMINI.md](./GEMINI.md)

## Назначение

TWM помогает руководителю технической службы определить, какими подтверждёнными компетенциями и допусками обладают специалисты, когда они доступны, какие работы могут выполнять и почему система рекомендует конкретного исполнителя.

TWM не является системой расчёта заработной платы, SCADA или полноценной EAM/CMMS. На первом этапе технические задания и оборудование представлены в облегчённой модели; интеграции с корпоративными системами планируются отдельно.

## Состояние проекта

Проект находится на этапе архитектурной подготовки. HTML-прототип v0.1 демонстрирует ключевые экраны и сценарии, но не является production-системой: он не содержит серверной базы данных, серверной аутентификации, совместной работы и промышленного механизма аудита/прав.

## Предлагаемый стек

- Frontend: React + TypeScript + Vite.
- Backend: Python + FastAPI + Pydantic.
- Database: PostgreSQL.
- ORM/migrations: SQLAlchemy 2.x + Alembic.
- Local development: Docker Compose.
- Tests: Pytest/HTTPX, Vitest/Testing Library, Playwright.
- CI: GitHub Actions.

Технологический стек и версии зависимостей фиксируются в архитектурных документах и lock-файлах до bootstrap.

## Запуск текущего прототипа

Для прототипа не нужны npm-пакеты:

```bash
python -m http.server 8000
```

Откройте `http://127.0.0.1:8000/TWM_Configurable_Prototype_v0.1.html`, если сервер запущен из корня репозитория.

Не используйте прототип для реальных персональных данных, юридически значимых документов или принятия решений по промышленной безопасности.
