# TWM — Technical Workforce Management

Конфигурируемое веб-приложение для управления внутренними техническими службами производственного предприятия: механика, электрика, энергетика, АСУ ТП, робототехника, метрология и другие инженерные подразделения.

**Репозиторий:** `uzbatsu-beep/HRMS`  
**Прототип:** [TWM Configurable Prototype v0.1](./TWM_Configurable_Prototype_v0.1.html)  
**План разработки:** [docs/DEVELOPMENT_PLAN.md](./docs/DEVELOPMENT_PLAN.md)  
**Инструкции Gemini:** [GEMINI.md](./GEMINI.md)

## Назначение

Система помогает руководителям технических служб управлять структурой подразделений, компетенциями, квалификациями и допусками специалистов, сменами, доступностью, техническими заданиями и назначением исполнителей.

TWM не является системой расчёта заработной платы, SCADA или полной EAM/CMMS.

## Состояние проекта

Проект находится на этапе архитектурной подготовки. HTML-прототип демонстрирует основные экраны и сценарии, но не является production-системой: в нём нет серверной БД, серверной аутентификации, совместной работы и промышленного механизма аудита и разграничения доступа.

## Предлагаемый стек

- Frontend: React + TypeScript + Vite.
- Backend: Python + FastAPI + Pydantic.
- Database: PostgreSQL.
- ORM/migrations: SQLAlchemy 2.x + Alembic.
- Local development: Docker Compose.
- Tests: Pytest/HTTPX, Vitest/Testing Library, Playwright.
- CI: GitHub Actions.

Версии зависимостей фиксируются после проверки совместимости на этапе bootstrap.

## Запуск прототипа

Из корня репозитория:

```bash
python -m http.server 8000
```

Откройте `http://127.0.0.1:8000/TWM_Configurable_Prototype_v0.1.html`.

Не используйте прототип для реальных персональных данных, юридически значимых документов или решений по промышленной безопасности.
