# TWM — Configurable Prototype v0.1

Интерактивный frontend-прототип системы Technical Workforce Management для внутренней технической службы производственного предприятия.

## Запуск

1. Распакуйте архив.
2. Для надёжного сохранения данных запустите локальный HTTP-сервер в папке проекта: `python -m http.server 8000`.
3. Откройте `http://127.0.0.1:8000` в браузере.
4. Также можно открыть `index.html` напрямую, но доступность `localStorage` для `file://` зависит от браузера.
5. Приложение не требует установки npm-пакетов и не использует интернет.

## Реализованные сценарии

- Навигация по модулям: обзор, персонал, компетенции, документы/допуски, планирование, технические задания, аналитика, конфигуратор.
- Создание и редактирование карточек сотрудников.
- Настраиваемая организационная структура.
- Каталог компетенций: добавление, редактирование, группировка по категориям.
- Конфигурируемые шкалы оценки навыков.
- Дополнительные поля карточки сотрудника.
- Настройка типов допусков, каталога ролей и демонстрационных разрешений.
- Настройка статусов технического задания и включение/отключение модулей.
- Реестр квалификационных документов с демонстрационной проверкой срока действия.
- Создание технических заданий с требованиями к навыкам и обязательным допускам.
- Подбор исполнителей с разделением жёстких блокирующих ограничений и оценки соответствия.
- Назначение исполнителя, учёт плановой загрузки и проверка ограничений при ручном выборе исполнителя.
- Экспорт резервной копии JSON, импорт JSON, экспорт персонала и матрицы компетенций в CSV.
- Локальное сохранение изменений в `localStorage`.

## Демонстрационные ограничения

Это frontend-прототип, а не production-система. Нет backend, серверной БД, реальной аутентификации, серверного RBAC, журнала аудита, совместной работы, загрузки защищённых документов, полноценного календарного движка и производственного workflow engine. Не используйте его для реальных персональных данных, юридически значимых документов и управления допусками.

Алгоритм подбора иллюстрирует принцип: обязательные допуски, минимальные навыки, доступность и упрощённая оценка свободной мощности применяются как жёсткие фильтры. Это не валидированный алгоритм промышленной безопасности.
